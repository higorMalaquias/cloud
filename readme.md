# ☁️ Portfólio - Computação em Nuvem

## 📚 Sobre o Projeto

Este repositório contém o desenvolvimento da atividade prática da disciplina **Computação em Nuvem**, do curso de **Engenharia de Software**.

O trabalho tem como objetivo demonstrar a configuração de um ambiente de desenvolvimento utilizando **Java**, **Apache NetBeans** e o framework **CloudSim**, permitindo a execução de simulações de infraestrutura em nuvem.

---

## 🎯 Objetivos da Atividade

* Instalar e configurar o Apache NetBeans.
* Instalar e configurar o Java Development Kit (JDK).
* Configurar o framework CloudSim.
* Criar um projeto Java utilizando o NetBeans.
* Executar o exemplo prático `CloudSimExample1`.
* Validar o funcionamento do ambiente de simulação em nuvem.

---

## 🛠️ Tecnologias Utilizadas

* Java
* Apache NetBeans
* CloudSim
* Computação em Nuvem

## ⚙️ Metodologia

### 1. Instalação das Ferramentas

Foi realizada a instalação das seguintes ferramentas:

* Apache NetBeans
* Java JDK
* CloudSim

### 2. Configuração do Ambiente

Após a instalação:

* Foi criado um projeto Java denominado **Redes**.
* O arquivo `CloudSimExample1.java`, localizado na pasta `examples` do CloudSim, foi adicionado ao projeto.
* As bibliotecas JAR do CloudSim foram importadas para o projeto.

### 3. Execução

Com o ambiente configurado:

1. Abrir o projeto no NetBeans.
2. Executar o projeto utilizando a opção **Run Project**.
3. Verificar o resultado na janela **Output**.

---

## 📈 Resultados Obtidos

A execução do exemplo foi realizada com sucesso, apresentando a mensagem:

```text
BUILD SUCCESSFUL
```

Esse resultado confirma que:

* O Java está corretamente instalado.
* O NetBeans está configurado adequadamente.
* As bibliotecas do CloudSim foram importadas corretamente.
* O ambiente está pronto para futuras simulações em nuvem.

## ✅ Conclusão

A atividade permitiu o primeiro contato prático com a utilização do framework CloudSim para simulação de ambientes de computação em nuvem.

A configuração correta do ambiente possibilita a realização de estudos mais avançados envolvendo:

* Datacenters
